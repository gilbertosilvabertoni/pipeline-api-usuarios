# Pipeline API Usuários

Mini pipeline ETL utilizando Python, pandas e uma API pública.

## Objetivo

Consumir dados JSON de uma API,
transformar os dados em um DataFrame
e exportar um CSV organizado.

## Fluxo do Pipeline

API → JSON → pandas → transformação → CSV

## Tecnologias

- Python
- pandas
- requests
- Google Colab

## Aprendizados

- Consumo de APIs REST
- Manipulação de JSON
- DataFrames com pandas
- Extração de dados aninhados
- Exportação CSV
